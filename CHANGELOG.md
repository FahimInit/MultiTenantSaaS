### Phase 4 — Advanced Backend Capabilities
- **Distributed Redis Caching & Epoch Invalidation (`SaaS.Application`, `SaaS.Infrastructure`):** Added `ICacheService`, `ITenantPermissionCacheInvalidator`, `DistributedCacheService` (Redis/distributed memory cache with O(1) per-tenant authorization epoch keys and graceful database fallback on cache errors), `CachedTenantMembershipResolver`, `DistributedCacheHealthCheck`, and `TenantCacheInvalidationInterceptor` ensuring EF Core commits to tenants, roles, role permissions, or memberships automatically synchronize cache state alongside explicit handler invalidation.
- **API Usage Metering & Background Maintenance (`PlatformMaintenanceRunner`):** Added `ITenantUsageTracker` (`BufferedTenantUsageTracker` using lock-free per-tenant monthly aggregation flushed atomically via PostgreSQL `ON CONFLICT UPSERT`), `ITenantContextSetter.SetSystemJobTenant` for isolated per-tenant maintenance scopes, and `PlatformMaintenanceHostedService` to expire overdue pending invitations and trials (recording tenant `AuditLog` and `SubscriptionHistory` entries) and purge expired/revoked refresh tokens older than 30 days.
- **Rate Limiting & Email Transport:** Updated `RateLimitingExtensions` with configurable per-tenant API partitioning, auth endpoint fixed-window partitioning without overwriting explicit `[EnableRateLimiting]` attributes (`Program.cs`), and RFC 9457 `application/problem+json` `429` responses with `Retry-After` fallback headers; added `SmtpEmailService` (`EmailOptions`) alongside `DevelopmentEmailService` outbox and wired Redis 7 into `docker-compose.yml` and `.env.example`.
- **Tests & Bug Fixes:** Fixed untracked entity projections in `MembershipStore.FindMemberDetailAsync` and `SubscriptionStore.GetTenantSubscriptionWithPlan*Async`; verified **69/69 passing tests** across unit tests and live PostgreSQL 17 + Redis 7 Testcontainers suites plus `docker compose config`.

### Phase 3 — Core Business Modules
- **Invitations & Membership Management (`SaaS.Domain`, `SaaS.Application`, `SaaS.API`):** Added `TenantInvitation`, SHA-256 opaque invite tokens (`OpaqueTokenService`), 7-day expiry, email-domain restriction enforcement from `TenantSettings`, duplicate pending invite guard (PostgreSQL partial unique index `status = 'Pending'`), resend/revoke, verified email matching on accept (`POST /api/v1/invitations/accept`), paginated/sortable/filterable member directory (`GET /api/v1/members`), role & status updates, and last active `ORG_OWNER` protection (`last_owner_protected`).
- **RBAC & Custom Roles (`RolesController`):** Exposed permission catalog (`GET /api/v1/permissions`) and tenant role management (`GET/POST /api/v1/roles`, `PUT/DELETE /api/v1/roles/{roleId}`) with plan feature gating (`AllowCustomRoles` / `MaxCustomRoles`), reference checks on delete, and anti-privilege-escalation guard (`PermissionHierarchyGuard`).
- **Subscriptions, Quotas & Billing (`SubscriptionsController`):** Added `SubscriptionPlan` (`FREE`, `PRO`, `ENTERPRISE`), `TenantSubscription` (trialing/active/canceled/expired with `xmin` concurrency token), immutable `SubscriptionHistory`, `TenantUsageSnapshot`, `IPaymentProvider` + `MockPaymentProvider`, downgrade conflict protection, and expired-trial workspace write blocking while retaining billing/upgrade access.
- **Audit Querying, Tenant Dashboard & Platform Admin (`AuditLogsController`, `DashboardController`, `PlatformController`):** Implemented paginated tenant audit filtering (`GET /api/v1/audit-logs`), single-pass aggregate tenant dashboard metrics (`GET /api/v1/dashboard`), and `[PlatformAdminOnly]` oversight endpoints (`GET /api/v1/platform/dashboard`, tenant suspension/reactivation, plan catalog management, and platform-wide security/audit search).
- **Database Migration & Tests:** Added `AddBusinessModules` EF Core migration with composite FK `(tenant_id, role_id)` on invitations and partial unique indexes; extended seeded data (`Acme Corp` on Pro, `Globex Labs` on Free); verified **62/62 passing tests** across unit and live PostgreSQL Testcontainers suites.

### Phase 2 — Identity & Multi-Tenant Foundation
- **Domain Model (`SaaS.Domain`):** Added `Tenant`, `TenantSlug` (normalized + reserved slug protection), `TenantSettings`, `TenantRole`, `RolePermission`, `PermissionCatalog` (`SystemRoleCodes` + 14 tenant permissions), `TenantMembership`, `UserSession`, `RefreshToken`, and `AuditLog` (`AuditScope`, `AuditCategory`).
- **PostgreSQL Schema (`SaaS.Infrastructure`):** Added explicit EF Core configurations, `AddIdentityAndTenantFoundation` migration, composite alternate key `(tenant_id, id)` on `tenant_roles`, composite FK `(tenant_id, role_id)` on `tenant_memberships`, `xmin` optimistic concurrency tokens, `jsonb` audit metadata, fail-closed `AuditLog` global query filter, and `DatabaseSeeder` (Platform Admin, Acme Corp, Globex Labs, and multi-tenant user).
- **Identity & Tenant Modules (`SaaS.Application` / `SaaS.Infrastructure` / `SaaS.API`):** Implemented registration, email verification (`DevelopmentEmailService` outbox), login (`403 email_not_verified` enforcement), SHA-256 refresh token rotation with token-family reuse detection & session revocation, logout, password reset, session listing/revocation, profile query, organization creation (`POST /api/v1/tenants`), membership listing, tenant updates, settings updates, and permission-protected `[HasPermission]` / `[PlatformAdminOnly]` / `[UserScoped]` attributes.
- **Security & Isolation Middleware (`SaaS.API`):** Implemented `TenantResolutionMiddleware` validating `X-Tenant-Id` against active DB memberships and auditing denied cross-tenant attempts, plus `OnTokenValidated` active session verification.
- **Tests:** Added domain unit tests, application handler unit tests, and live PostgreSQL Testcontainers integration tests covering auth flows, token reuse revocation, email verification, and cross-tenant isolation (**46/46 passing** across all 3 test projects).
